語音編輯適合「文字已經在畫面上，但你想改它」的情境。

一般聽寫是從空白處輸入新文字；語音編輯則是先選取一段既有文字，再用語音告訴 VoxPen 要怎麼改。VoxPen 會把選取文字和你說的修改指令一起交給 LLM，最後把選取範圍替換成改好的版本。

## 適合拿來做什麼

- 把一句話改得更正式。
- 把英文翻成繁體中文。
- 把一段冗長文字縮短。
- 修正文法和標點。
- 把條列改成 email。
- 把醫療、技術或工作筆記整理得更清楚。

## 使用前先設定

語音編輯會用到兩個能力：語音轉文字和 LLM 文字編輯。

請先確認：

1. `設定 -> 語音` 已設定 STT 供應商，例如 Groq Whisper 或 OpenAI Audio API。
2. `設定 -> 潤飾` 已設定 LLM 供應商、模型和 API key。
3. `設定 -> 一般` 裡的語音編輯快捷鍵可用，預設是 `Ctrl+Shift+E`。

語音編輯的快捷鍵需要是組合鍵，避免在一般打字時誤觸。

## 基本流程

1. 在任何 app 裡選取一段文字。
2. 按住 `Ctrl+Shift+E`。
3. 說出你想怎麼改。
4. 放開快捷鍵。
5. VoxPen 會在放開快捷鍵後讀取仍然選取的文字，交給 AI 修改，再把選取範圍替換成修改後的版本。

放開快捷鍵前請讓原本那段文字保持選取狀態。VoxPen 會暫時使用剪貼簿讀取選取內容，完成後會盡量還原原本的剪貼簿文字。

例如你選取：

```text
這個版本應該有修好一些問題，你再試試看。
```

按住 `Ctrl+Shift+E`，說：

```text
改成比較正式、適合寄給客戶的語氣
```

可能得到：

```text
此版本已修正部分問題，請您再協助測試確認。謝謝。
```

## 例子 1：把口語改正式

選取：

```text
我晚點看一下，有問題再跟你說。
```

說：

```text
改成正式 email 語氣
```

輸出可能是：

```text
我稍後會再確認內容，如有任何問題會再與您聯繫。
```

## 例子 2：翻譯選取文字

選取：

```text
Please summarize the discussion and list the next steps.
```

說：

```text
翻成自然的繁體中文
```

輸出可能是：

```text
請摘要這次討論，並列出下一步行動。
```

## 例子 3：縮短一段文字

選取：

```text
這個功能目前大致上可以使用，不過有些邊界情況還需要測試，尤其是長時間錄音、網路不穩定，以及不同供應商回傳錯誤時的行為。
```

說：

```text
縮短成一句產品更新說明
```

輸出可能是：

```text
此版本改善長錄音、網路不穩與供應商錯誤時的可靠性。
```

## 常見問題

### 沒有反應？

先確認你真的有選取文字，而且放開快捷鍵時選取範圍仍然存在。語音編輯停止錄音後會複製目前選取內容；如果沒有文字被選到，VoxPen 無法知道要改哪一段。

### 可以用在瀏覽器、Slack、VS Code、Notion 嗎？

可以。只要那個 app 支援選取文字、複製、貼上，語音編輯就能運作。

### 可以用在 Word、Vim 或終端機嗎？

可以，前提是該 app 當下能保留選取範圍，並且一般的複製、貼上快捷鍵可用。VoxPen 會等你放開語音編輯快捷鍵後才複製選取文字，減少組合鍵干擾 Word、Vim 或終端機複製行為的機率。

### 跟聽我指令差在哪？

語音編輯是「改你已經選取的文字」。聽我指令是「從你的口頭指令生成一段新的可貼上內容」。

如果你想從零生成回覆、摘要、程式碼或清單，請看：[聽我指令教學](/zh-tw/blog/listen-command-guide)。
